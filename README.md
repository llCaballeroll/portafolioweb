# Portafolio — Luis Ángel Caballero Jardón

Portafolio profesional publicado en GitHub Pages: experiencia, inteligencia artificial aplicada, apps y juegos, habilidades, documentos y contacto.

## Diseño

- Basado en la guía de diseño de Apple (awesome-design-md): tipografía SF, acento azul único, tarjetas con línea fina.
- Tema claro y oscuro: sigue al sistema y se puede cambiar con el botón de la barra (se recuerda en el navegador).
- Responsive: celular chico, celular, tablet y escritorio, con menú desplegable en celular.
- Sin dependencias externas: HTML, CSS y un solo `site.js`.
